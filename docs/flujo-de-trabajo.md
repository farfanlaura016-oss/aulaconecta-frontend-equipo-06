Expliación De Los Comandos:

1. Git Commit: Guarda un registro permanente de los cambios realizados en el proyecto para conservar su historial.
2. Git Branch: Crear una nueva rama para desarrollar cambios sin afectar la rama principal.
3. Git Checkout: Permite cambiar entre ramas para trabajar en una version especifica del proyecto. 
4. Git Merge: Une los cambios de una rama con otra intregrando el trabajo realizado.
